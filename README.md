# 一个自己用的闹钟app

## Android 工程（Kotlin + Jetpack Compose）

本目录已包含可直接用 **Android Studio** 打开构建的 Gradle 工程，应用 ID：`com.nierduolong.morningbell`，产品名：**你尔多龙吗**。

### 如何构建 / 安装到小米手机

1. 安装 [Android Studio](https://developer.android.com/studio)，首次打开会自动拉取 Android SDK。
2. 用 Android Studio **Open** 本文件夹根目录（含 `settings.gradle.kts`）。
3. **一键打包发 APK**：在项目根目录执行 `./package_apk.sh`，会在 `dist/你尔多龙吗.apk` 生成安装包（默认先 `clean` 再构建，避免 KSP 偶发失败；要快可加 `./package_apk.sh --fast`）。
4. 若手动命令行构建：执行 `./gradlew :app:assembleDebug`，APK 位于  
   `app/build/outputs/apk/debug/app-debug.apk`，拷到手机安装即可（侧载）。  
   Room 已通过 KSP **生成 Kotlin**（`room.generateKotlin`），避免旧版 Java 生成物在增量构建里叠加导致 **`AppDatabase_Impl` 类重复**；若仍异常请先 `./gradlew clean`。
5. **首次在本机命令行构建**需要 `local.properties` 中的 `sdk.dir` 指向你的 SDK（仓库里有一份示例路径；若与你的电脑不一致请自行修改）。
6. **小米 HyperOS**：请在系统设置里为该应用开启 **自启动、后台无限制、精确闹钟** 等，否则可能被推迟或杀后台。
7. **日志拍摄提醒**：在「日志」页右上角铃铛里选择每小时 / 每 3 小时 / 随机 / 关闭，并设置「只在这段时间提醒」的活跃时段（默认 9:00–22:00）。提醒用 `AlarmManager` 精确闹钟自续期触发通知，点击通知直达拍摄页；开机后会自动补排。同样建议开启自启动、精确闹钟等系统权限以保证提醒不被系统杀掉。

### 功能定位

App 分三大 Tab：**日志**（默认启动页，仿 Setlog 的每日短视频记录 + 自动合成）、**闹钟**（原有定时闹钟 + 连锁闹钟）、**我的**（昵称、语录主题包、快捷入口）。已移除原「每日视频打卡」与「早起统计」两项功能，小芽 Companion 改为仅基于心情记录驱动成长。

视觉上统一为简约社交风：白底（深色模式纯黑）、近黑文字、发丝级描边，颜色只在强调处保留一点薄荷绿；内容区以视频缩略图网格为主体。

### 稳定性与存储

- 崩溃栈落盘在 `files/crash/`，「我的」页出现崩溃记录时可分享导出（无服务端也能排查）。
- 视频存 app 私有目录（免存储权限），按日归档；缩略图两级缓存并有 40MB 上限；启动时清理崩溃残留的孤儿文件（按文件名比对 + 多重保险，不会误删在册素材）。
- 数据库里存**相对路径**（`dailylog/` 起算），读取时才解析成绝对路径：换机、恢复备份、分区变化都不会让历史记录集体变成死链；首次升级会自动把旧的绝对路径归一化，找不到的文件按文件名重定位。
- 启动自愈有固定顺序：路径归一化 → 清孤儿文件 → 补合成昨天 → 套用保留策略。保留策略永远排在合成之后，保证不会清掉还没合成的日期。
- 云备份排除视频本体、保留数据库与设置（`res/xml/backup_rules.xml`），避免超出备份体积上限导致整体备份失败。
- Release 包不再允许数据库「推平重建」，缺失迁移会直接暴露而不是静默清库。
